# Money Exchange Application

A Java application that converts amounts between different currencies.

## Description

This project was developed as a university project. It is a money exchange application built with Java and Maven that lets a user convert a given amount from one currency to another with some other interesting features.

## What It Does

- Takes an amount and a source currency from the user
- Converts it to a chosen target currency using exchange rates
- Displays the converted result

## Technologies

- Java
- Maven

## How to Run

```bash
git clone https://github.com/IbrahimSeblini/Money-Exchange-application.git
cd Money-Exchange-application
./mvnw clean install
```

On Windows, use `mvnw.cmd` instead of `./mvnw`.
